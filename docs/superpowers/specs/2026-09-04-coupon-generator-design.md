# 優惠券產生器 - 設計文件

## 專案概述
單頁優惠券產生器，純前端 HTML+CSS+JavaScript，一個檔案完成。店家透過 LINE 官方帳號將優惠券頁面傳送給客戶，客戶掃描 QR Code 查看優惠內容，店家掃碼核銷。

## 技術架構
- **單一 HTML 檔案**：所有程式碼集中於一個檔案
- **CDN 依賴**：QR Code 產生使用開源 JS 套件（qrcodejs）
- **儲存**：localStorage 儲存設定值
- **部署**：Firebase Hosting
- **無後端**：純前端運作

## 頁面布局
採用「單頁切換」模式（方案A）：
- 點按鈕切換「優惠券顯示」與「後台設定」兩個畫面
- 手機體驗最佳，一次只看一個畫面

## 優惠券卡片設計

### 視覺風格
- 溫馨親子風：圓角卡片、柔和配色
- 主色調：咖啡色（#8B5A2B）呼應 LOGO
- 背景：淺米色或白色

### 卡片內容
```
┌─────────────────────────────────────┐
│ [LOGO]                              │
│                                     │
│   一次性優惠劵                       │
│   訂房享 9 折優惠                    │
│                                     │
│ ┌─────────────┬─────────────┐       │
│ │ 發送日期    │ 有效期限    │       │
│ │ 2026/09/04  │ 2026/12/04  │       │
│ └─────────────┴─────────────┘       │
│                                     │
│ 使用方式：                          │
│ - 訂房時請出示本券並告知服務人員      │
│ - 本券不得與其他優惠併用             │
│ - 每組訂房限使用一張                 │
│                                     │
│          ┌─────────┐                │
│          │ QR Code │                │
│          └─────────┘                │
└─────────────────────────────────────┘
```

### 日期計算邏輯
- 發送日期：自動抓取當天日期
- 到期日：發送日期 + 設定月數
- **月底溢位處理**：1/31 + 3 個月 → 4/30（非 5/1）

## QR Code 設計

### 內容格式
```
風自然|一次性優惠劵,訂房享9折優惠|2026/09/04|2026/12/04
```

### 掃描行為
- 客戶掃描：顯示優惠券頁面（隱藏設定區）
- 店家掃描：顯示原始文字，用於核銷對比

### 防偽邏輯
QR Code 圖片為靜態，內容凍結。頁面顯示可被竄改，但 QR Code 內容不變，店家掃碼可核對。

## 後台設定區

### 表單欄位
1. **店家名稱**：文字輸入框（預設：風自然親子時尚旅宿）
2. **優惠內容**：文字輸入框（預設：一次性優惠劵,訂房享 9 折優惠）
3. **效期月數**：數字輸入框（預設：3）
4. **是否啟用**：開關按鈕

### 儲存機制
- 點擊「儲存設定」按鈕
- 存入 localStorage
- 重整頁面後自動讀取上次設定
- 儲存成功後顯示提示

## 技術細節

### QR Code 套件
使用 CDN 引入 qrcodejs：
```html
<script src="https://cdn.jsdelivr.net/npm/qrcodejs@1.0.0/qrcode.min.js"></script>
```

### 月底溢位處理演算法
```javascript
function addMonths(date, months) {
  let result = new Date(date);
  result.setMonth(result.getMonth() + months);
  // 修正月底溢位
  if (result.getDate() < date.getDate()) {
    result.setDate(0); // 設為上個月最後一天
  }
  return result;
}
```

### 響應式設計
- 手機：單欄佈局
- 平板/電腦：卡片置中，最大寬度限制

### 使用方式說明（固定文字）
```
使用方式：
- 訂房時請出示本券(QR CODE),並告知服務人員
- 本券不得與其他優惠併用
- 每組訂房限使用一張
```
